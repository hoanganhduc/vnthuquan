Categories And Formats
======================

MVP category support is read-only.

.. code-block:: bash

   vnthuquan categories list
   vnthuquan categories show 23
   vnthuquan formats list

Format IDs:

.. code-block:: text

   text   0
   image  1
   pdf    2
   audio  3
   epub   4

Category + format filtering and bulk category downloads are deferred.
